# Курсовая работа «Продвинутый JavaScript» — Instapro

### Какую функциональность удалось реализовать:

- Интегрировала верстку списка постов с реальным сервером через API.
- Реализовала страницу динамического добавления нового поста с загрузкой картинок в облако.
- Реализовала страницу просмотра постов конкретного пользователя при клике на его имя/аватарку.
- Реализовала интерактивный функционал лайков (добавление и снятие лайка с мгновенным обновлением счетчика на экране).
- Настроила независимую песочницу данных (персональный ключ `zarina-gulieva`).

### Первоначальная оценка и фактически затраченное время:

- **Планируемое время:** 6-8 часов.
- **Фактически затраченное время:** около 4 часов (благодаря пошаговой доработке архитектуры Алёны Юдиной без переписывания проекта с нуля).
